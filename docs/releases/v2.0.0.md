# jwDaily Hydration Log v2.0.0 — stable release

**Release date: 22 November 2026.** This is a **stable** release, not a prerelease.

## Overview

v2.0.0 packages the user-accepted functionality from v1.5.1-beta.4 as a stable HACS release. It also reorganizes the public GitHub repository so that the main README explains the integration, while historical release notes, implementation audits and old release automation are retained in clearly labeled documentation archives.

This is a **release and repository-documentation milestone**, not a new data-model version or a breaking feature migration.

## Included functionality

- Multiple independent hydration profiles, per-profile targets and display settings.
- Liquid, Cup and Quick button management with native history preservation.
- Add drink, history editing, progress, daily charts, 24-hour/7-day sensors and HA services.
- Six-sheet Excel export, including Yes/No values and content-fitted technical ID/MDI columns.
- Full-profile ZIP backup and selective restore (**Everything**, **Settings only**, **Data only**).
- Restore preview with an unambiguous filename, profile name, full content comparison and safe confirmation.
- Bottom-right Close control on Settings dialogs.

## Repository and documentation cleanup

- Replaced the historical release-log-heavy root README with a concise user/product guide.
- Moved older release notes to \`docs/archive/releases/\`; created a release index at \`docs/RELEASE_NOTES.md\`.
- Moved technical acceptance/audit notes under \`docs/archive/reviews/\` and historical ApexCharts examples under \`docs/archive/examples/\`.
- Consolidated the changelog at \`docs/CHANGELOG.md\` and linked current guides via the root README.
- Archived obsolete per-beta GitHub Actions publishers under \`docs/archive/workflows/\`; the normal CI, HACS/hassfest validation and new v2.0.0 publisher remain active.
- Retained historical releases and source code provenance. No past release tags are overwritten.

## Storage and compatibility

No current hydration record, target, profile, Cup, Liquid or Quick button needs migration to v2.0.0. The integration continues using its established native storage and backup formats.

Back up Home Assistant and download the integration's current Full Backup ZIP before updating. Install **v2.0.0** from HACS, restart Home Assistant Core and refresh the browser.

## Quality gates

Publication requires offline backend/storage/restore tests, six-sheet Excel checks, real Chromium UI regression at multiple viewport widths, HACS validation and Home Assistant hassfest. The generated ZIP is CRC-checked, file-by-file compared with source files and SHA-256 verified. A matching \`.sha256\` checksum file is published with the release.

## Rollback and historical documentation

Previous release tags, including v1.5.0 and v1.5.1-beta.4, remain accessible on GitHub Releases. Use backups for actual data rollback; simply installing older code is not a substitute for restoring compatible data.
