# jwDaily Hydration Log v2.0.1 — stable maintenance release

**Release date:** 23 November 2026 · **Type:** stable · **Previous stable:** v2.0.0

## Fixed: Excel export window descriptions

The **Export to Excel** dialog previously said the workbook contained *four sheets*, even though the integration already exported six. The secondary Settings Export page had the same outdated description. Both now correctly describe the six-sheet Excel workbook:

1. **Hydration log** — individual drink records.
2. **Daily intake** — daily totals and liquid breakdown.
3. **Settings - Liquid Types** — definitions, visibility and icons.
4. **Settings - Cup types** — cup names, icons and default volumes.
5. **Settings - Quick buttons** — profile-specific Quick buttons.
6. **Settings - Profiles** — targets, units and profile display settings.

There are **no changes to XLSX format, actual exported values, drink history, stored profiles, liquid/cup definitions, backup format or restore behaviour**. This is a UI wording correction with synchronized frontend/backend version identifiers.

## Verification

- The existing Excel workbook, storage, backup/restore and migration regression suites.
- Chromium browser tests verify the real export dialog at supported screen widths.
- A regression ensures that the two user-facing UI locations reference six sheets and rejects stale four-sheet descriptions.
- Home Assistant hassfest, HACS verification, JavaScript syntax checks and a ZIP CRC/SHA-256 release gate.

## Install / upgrade

Install **v2.0.1** through HACS, restart Home Assistant Core and refresh the browser. Create a Home Assistant backup and download the integration's current Full Backup ZIP before upgrading.

The already published v2.0.0 release remains available unchanged. Screenshots in the README and User guide were captured from v2.0.0, whose layout is retained.
